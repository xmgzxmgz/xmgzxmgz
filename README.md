## How I Build

> 为什么仓库里 Python 最多、star 最高的却是 Rust？因为它们是同一条流水线的两端。

| 层级 | 语言 | 干什么 |
|---|---|---|
| **试验层** | Python | 验证想法、对接尚未公开的接口、先把路径跑通 |
| **交付层** | Rust / C# / Swift / Kotlin / C | 把验证过的逻辑做成能装、能长期跑、不掉登录态的成品 |
| **网关层** | Go / TypeScript | 多模型聚合、协议转换、前后端拼装 |
| **展示层** | HTML / ECharts | 只读、零依赖、打开就能看的面板 |

一句话：**用 Python 换速度，用编译型语言换稳定。**
